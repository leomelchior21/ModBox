# MAKITAS VS ZOMBIES artwork

Created with the built-in imagegen tool using the prompts below. Selected PNGs were copied into the workspace and encoded as WebP at quality 0.92, preserving dimensions and sprite transparency. Original PNGs remain in the Codex generated-images directory. Production assets total about 1.5 MB.

- `public/art/makitas/cover.webp`: library cover and launch backdrop.
- `public/art/makitas/yard.webp`: painted gameplay environment.
- `public/art/makitas/sprites.webp`: transparent four-column, two-row atlas. Top row: saw, charger, barricade, frost saw. Bottom row: worker, hardhat, sprinter, foreman. Defenders are mirrored at render time. Canvas adds rotating blades, bounce, health bars, frost rings and combat feedback.

No official logos or existing Plants vs Zombies characters are used. The registered SVG cover and canvas silhouettes provide a fallback if art cannot load.
